# TMAP 업체 거리 필터

기준 위치에서 **일정 거리(예: 50km) 이내의 업체만 골라내는** GUI 프로그램입니다.
업체 목록(위경도 포함)을 받아 TMAP 화물차 경로로 실제 도로거리·예상시간을 구합니다.

---

## 1. 설치

```bash
pip install -r requirements.txt
```

> GUI는 파이썬 기본 내장 Tkinter를 쓰므로 추가 설치가 없습니다.

## 2. APP KEY 발급 (최초 1회)

조회에는 SK open API 의 APP KEY 가 필요합니다. **키는 프로그램 실행 시 직접 입력**합니다.

1. **[SK open API - TMAP 상품 페이지](https://openapi.sk.com/products/detail?svcSeq=60&menuSeq=122)** 접속 후 로그인
2. **My Project → 프로젝트 생성**
3. 프로젝트에 **TMAP API**(전체주소 Geocoding, 화물차 경로안내) 추가
4. 발급된 **APP KEY** 복사 → 실행 화면에 붙여넣기

---

## 3. 사용법 (GUI)

```bash
python tmap_gui.py
```

창에 다음을 입력하고 **실행**을 누르면 됩니다.

| 입력 | 설명 |
| --- | --- |
| **APP KEY** | 발급받은 키를 직접 붙여넣기 |
| **기준 주소** | 출발 기준점 주소 (예: `서울특별시 중구 세종대로 110`) |
| **또는 좌표** | `위도,경도` 직접 입력 (입력 시 주소는 무시) |
| **기준 거리 (km)** | 이 거리 이내 업체만 결과에 남김 (예: 50) |
| **우회계수** | 직선거리 → 도로거리 추정 배수 (기본 1.2) |
| **대상 파일** | 콘크리트 / 아스콘 선택 |

**입력 데이터** (저장소에 포함)

| 파일 | 내용 |
| --- | --- |
| `콘크리트_업체_좌표.csv` | 레미콘/콘크리트 업체 목록 |
| `아스콘_업체_좌표.csv` | 아스콘 업체 목록 |

**결과**: `콘크리트_50km이내.csv` 처럼 `{종류}_{거리}km이내.csv` 파일이 같은 폴더에
생성됩니다. (도로거리 가까운 순 정렬)

| 업체명 | 주소 | 거리(km) | 시간 | 직선거리(km) |
| --- | --- | --- | --- | --- |

> 동작: 먼저 직선거리×우회계수로 멀리 있는 곳을 빠르게 거른 뒤, 남은 곳만
> 실제 도로거리/시간을 조회합니다. (조회 시간·호출량 절감)

## 4. 추가 기능 — 주소 목록의 거리/시간 일괄 조회 (`tmap_distance.py`)

주소만 들어 있는 CSV(`업체명, 주소`)를 넣으면, 기준 위치에서 각 주소까지의
**거리와 예상 이동시간**을 한 번에 구해 줍니다. (좌표가 없어도 됨 — 주소를 자동 변환)

```bash
python tmap_distance.py --app-key 발급받은키 --origin "서울특별시 중구 세종대로 110" -i input.csv
```

- `--app-key` 생략 시 실행 중 입력을 요청합니다.
- 결과는 `output.csv` (업체명·주소·위도·경도·거리(km)·예상시간·상태)로 저장됩니다.

입력 CSV 예시:

```csv
업체명,주소
(주)원클린,경기도 이천시 부발읍 부발중앙로 85
```

## 5. 참고

- **CLI로 필터 실행**: GUI 없이도 사용 가능
  ```bash
  python tmap_filter.py --app-key 발급받은키 --origin "부산 강서구 평강로 271" --max-km 50
  python tmap_filter.py --app-key 발급받은키 --origin-latlon 35.16,128.99 --max-km 30
  ```
- **차량 제원**: `config.py`(없으면 `config_example.py` 복사)에서 화물차 폭/높이/중량/길이를
  조정합니다. 기본값은 20톤 덤프트럭 기준입니다.
- 입력 CSV 인코딩(UTF-8/CP949)은 자동 인식합니다.
